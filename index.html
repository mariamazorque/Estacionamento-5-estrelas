Dados e aparelhos

Tudo o que é lançado aqui fica salvo no banco de dados na nuvem (Supabase) e aparece em qualquer aparelho conectado.

Trazer dados de outro app

Aceita a cópia de segurança do sistema em Python (Streamlit), a do app no Claude e o arquivo "Exportar para Python" do dashboard antigo.

Se importar o mesmo arquivo duas vezes, nada é duplicado.

Usar em vários aparelhos

  1. Abra o endereço deste site no celular, tablet ou computador e entre com o seu e-mail e senha.
  2. No celular, use Adicionar à tela inicial no menu do navegador para abrir como aplicativo.
  3. O aparelho fica conectado até você clicar em Sair, no topo.

Cópia de segurança

Baixa todos os dados em um arquivo JSON. Guarde uma cópia todo mês.
